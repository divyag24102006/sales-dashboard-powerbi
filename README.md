# Sales Dashboard using Power BI

## 📌 Project Overview
This project is a beginner-level interactive Sales Dashboard created using Microsoft Power BI to analyze sales performance and convert raw data into meaningful business insights.

## 📊 Dashboard Features
- Total Sales KPI
- Product-wise Sales Analysis
- Region-wise Sales Comparison
- Sales Trend Analysis
- Interactive Date Slicer

## 🛠 Tools Used
- Microsoft Power BI
- Data Visualization
- Microsoft Excel (Dataset)

## 📈 Key Insights
- Total Sales: 259K
- Highest Sales Product: Laptop
- West Region recorded the highest sales.
- Sales performance can be analyzed over time using interactive visuals.
